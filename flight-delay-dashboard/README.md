## Projects

### Flight Delay Dashboard (Tableau)

Developed an interactive Tableau dashboard analyzing U.S. airline flight performance using Department of Transportation data.

The dashboard tracks flight volume, on-time performance, delays, cancellations, airline performance, and cancellation reasons through KPI cards and interactive visualizations.

Skills:
- Tableau
- Dashboard Design
- Calculated Fields
- KPI Development
- Data Visualization
- Business Analytics
- Data Storytelling

Visualizations:
- KPI Cards (Total Flights, On-Time %, Delayed %, Canceled %)
- Monthly Flight Trend Analysis
- Flights by City
- Top Airlines by Delay Rate
- Top Airlines by Cancellation Rate
- Average Departure Delay
- Cancellation Reason Donut Chart
